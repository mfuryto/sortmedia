# Security policy

## Reporting a vulnerability

Please do not disclose security issues in a public GitHub issue. Use GitHub's
private vulnerability reporting for this repository when available, or contact
the repository owner privately through their GitHub profile.

Include affected versions, reproduction steps, and the possible impact. Do not
include private media or metadata. You can expect acknowledgement as soon as
the report has been reviewed.

## Scope

Path traversal, unintended file overwrite or deletion, unsafe undo behavior,
command injection, and permission-boundary problems are considered security
issues. Sortmedia intentionally operates only with the permissions of the user
who runs it.
